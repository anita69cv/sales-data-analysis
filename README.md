# 🛒 Sales Data Analysis (Excel, SQL, Tableau)

## 📌 Objective
Analyze retail sales data to identify trends, top-performing regions, and profit patterns.

## 🛠 Tools Used
* Microsoft Excel (Data Cleaning)
* MySQL (Data Analysis)
* Tableau (Data Visualization)

## 📊 Dashboard Features
* Sales by Region
* Profit by Category
* Monthly Sales Trend
* Profit vs Loss Analysis
* Interactive Filters

## 🧠 Key Insights
* Certain regions generate higher sales than others
* Some product categories are more profitable
* Sales show variation across months
* Not all sales generate profit (loss observed in some cases)

## 📁 Files Included

* Dataset (Excel + CSV)
* SQL Queries
* Tableau Dashboard (.twbx)

## 🚀 Conclusion

This project demonstrates end-to-end data analysis using Excel, SQL, and Tableau to derive meaningful business insights.
